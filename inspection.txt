CORRECTIONS AFTER LOCAL VERIFICATION
------------------------------------
Problem 1:
Drizzle migration reported:
  Error Please provide required params for Postgres driver:
  [x] url: undefined

Cause:
drizzle.config.ts was not explicitly loading .env.local.

Fix:
drizzle.config.ts now loads:
  config({ path: ".env.local" });
  config();

Problem 2:
TypeScript checked archived backup source files under backups/ and found
legacy Telnyx code using unsupported credentials/destination properties.

Fix:
tsconfig.json now excludes:
  backups

IMPORTANT
---------
The previous verification script printed a green success line even after
migration/typecheck failures because it did not terminate before that line.
The corrected verification script uses:
  $ErrorActionPreference = "Stop"
and explicit exit-code checks, so success is printed only when all checks pass.
