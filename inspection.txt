8. 5SIM API Verification Notes

Based on the current 5SIM API v1 documentation (https://docs.5sim.net/):

    Auth: Authorization: Bearer <token> header
    Countries: GET /v1/guest/countries — returns all countries with product availability
    Products: GET /v1/guest/products/{country}/{product} — returns operators, prices, availability
    Prices: GET /v1/guest/prices or per-country — returns pricing by product/country/operator
    Purchase: GET /v1/user/buy/activation/{country}/{operator}/{product} — buys an activation number
    Check: GET /v1/user/check/{order_id} — returns order status and SMS codes
    Cancel: GET /v1/user/cancel/{order_id} — cancels an order
    Finish: GET /v1/user/finish/{order_id} — marks order as finished
    Product types: activation (OTP) vs hosting (monthly) — must filter for activation only
    Response fields: id, phone, operator, product, country, status, price, sms[]

Key status values from 5SIM: PENDING, RECEIVED, CANCELED, TIMEOUT, FINISHED, BANNED
